Software

I develop and contribute to open-source Julia packages for dynamic optimization and GPU-accelerated nonlinear programming, mostly around ExaModels.jl and MadNLP.jl.

  • ExaModelsCollocation.jl: Helper functions for formulating dynamic optimization problems via orthogonal collocation in ExaModels.jl, with support for adaptive meshes and unknown time horizons. I am the main developer of the package.
  • ExaModelsPEtab.jl: Formulates PEtab parameter estimation problems as ExaModels using orthogonal collocation, which can then be solved with MadNLP on CPUs or GPUs. I am the main developer and used it for the systems biology benchmarks in [C1].
  • ParametricNLPModels.jl (Developer): A data structure for computing parametric sensitivities in nonlinear programming models, built on NLPModels.jl. I wrote the parametric Jacobian and Hessian interface.
  • ExaModels.jl (Contributor): A sparse automatic differentiation and algebraic modeling tool for nonlinear programs on CPUs and GPUs. I am adding automatic differentiation with respect to parameters, which computes the parametric constraint Jacobian and Lagrangian Hessian needed for sensitivity calculations.
  • MadNLP.jl (Contributor): A nonlinear programming solver based on the filter line-search interior-point method, with GPU support. I am adding parametric sensitivity calculations from derivatives with respect to parameters.
  • EOptInterface.jl: An abstraction layer for optimizing componentized equation-oriented models built in ModelingToolkit.jl using JuMP.jl. I was the main developer from 2024 to 2025 as an undergraduate in the PSOR Lab [J1].
